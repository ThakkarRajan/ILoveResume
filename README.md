## Why I Love Resumes

Most people send the same resume to every job. Recruiters and applicant tracking systems (ATS) look for role-specific keywords and clear structure.

**I Love Resumes** helps you tailor one resume per posting — with suggestions you review and edit — then download a clean Word or PDF file. Core drafting and export stay free. No paywall for the main workflow.

> You stay in control. Suggestions are starting points, not claims about interviews, rankings, or employer decisions.

---

## How it works

1. **Sign in** with Google.
2. **Upload or paste** your resume and the job description.
3. **Review AI suggestions** for wording and keyword alignment.
4. **Edit** any section on the result page until it sounds like you.
5. **Export** as Word (`.docx`) or PDF and apply.

## Tech stack (developers)

| Layer | Stack |
|-------|--------|
| App | [Next.js](https://nextjs.org) (App Router), React, Tailwind CSS |
| Auth & data | Firebase Authentication, Firestore, Storage |
| Export | `docx`, `pdf-lib`, browser download helpers |
| Hosting | Vercel |

Node **24.x** required (`package.json` engines).

### Local development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Copy environment variables from your team’s secrets store (Firebase, AI backend, analytics). Never commit `.env` files.

```bash
npm run build   # production build
npm run start   # serve production build
npm run lint    # ESLint
```
